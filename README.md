# Orbit - Motion & Gravity Lab

An interactive physics website with free-fall, projectile-motion, and Earth-orbit labs.

This branch contains only the standalone website for GitHub Pages.

To publish: open repository Settings > Pages, choose Deploy from a branch, select gh-pages and / (root), then Save.

The site uses no backend, external assets, account sign-in, or API keys.

## Orbit Simulators

Open [the simulator collection](https://evan-cpu266.github.io/Evan/simulators/).
It contains 13 playable topics covering forces, work, energy and momentum, with
Play/Pause, Reset, playback speed and a timeline. Every included topic has a
simulator; no practice questions are included. The original motion, acceleration
and graph labs remain at the homepage.

The simulator is a standalone offline HTML file with no external assets or backend.
`orbit-simulators.html` and `orbit-lessons.html` are aliases for the same collection.
